# ADHD Life Hacks: a 12-lesson audio course

12 two-host audio lessons of about 2 minutes, each with a card, one small thing to try and one rule to keep. Built with [Claudemy](https://github.com/assafkip/claudemy) from 24 public sources (NHS trusts, CHADD, ADDA, Cleveland Clinic, Stanford, University of Minnesota, a CBT-for-ADHD paper, two TikTok studies). Audio voiced with ElevenLabs.

Self-help strategies, not treatment. Progress is stored only in the visitor's browser.
